Vehicle Damage Detection & Cost Estimator
Overview

This project is an AI-powered web application that detects vehicle damage such as dents and scratches from uploaded car images and estimates repair costs automatically.

The application uses:

YOLOv11 Object Detection Model
Roboflow API
Streamlit Web Interface
Python
Features
Detects:
Dents
Scratches
Displays:
Bounding boxes
Confidence scores
Damage severity
Estimated repair cost
Supports:
Multiple damages in one image
Real-time image upload
Professional web interface
Tech Stack
Python
Streamlit
Roboflow
YOLOv11
Pillow
Requests
